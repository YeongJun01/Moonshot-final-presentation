프로젝트 개요

본 프로젝트는 주민들과 아파트 관리 단체를 위한 상호 관리 플랫폼으로 슈퍼어드민, 어드민, 유저의 3가지 유형으로 구분되어 사용할 수 있습니다.

핵심 기능

  • 공지사항 관리 (관리자 → 입주민 전달)
  • 민원 시스템 (입주민 → 관리자 요청)
  • 투표 기능 (의사결정 참여)
  • 실시간 알림 (Socket / SSE)
  • 입주민 명부 관리 (CSV 업로드)

개발 환경 및 사용 스택

  • Backend: Node.js, Express
  • Database: PostgreSQL
  • Deployment: AWS EC2, Nginx, PM2
  • CI/CD: GitHub Actions
  • API 문서화: Swagger
  • 협업 도구: GitHub, Notion, Discord

팀 구성 및 역할

  • 김지선 – Complaint, Notice, Poll, Pollvote, Event
  • 나영준 – Apartment, ResidentList, Comment
  • 이상운 – Auth, User, Notification

협업 방식

  • Git Flow 기반 브랜치 전략
  • Daily Scrum
  • api 단위 개발

커밋 컨벤션

  • ✨ feat : 새로운 기능 추가
  • 🐛 fix : 버그 수정
  • 📝 docs : 문서 수정
  • 🛠️ refactor : 리팩토링
  • ✅ test : 테스트 추가/수정
  • 🔥 remove : 코드/파일 삭제
  • ♻️ chore(update) : 유지보수 작업(빌드/설정/패키지 등)

Controller → Service → Repository
요청 / 비즈니스 로직 / DB 접근 계층 분리

- Controller
  · HTTP 요청/응답 처리
  · 입력값 검증 및 예외 처리

- Service
  · 비즈니스 로직 담당
  · 트랜잭션 관리

- Repository
  · DB 접근 전담
  · Prisma 기반 데이터 처리
